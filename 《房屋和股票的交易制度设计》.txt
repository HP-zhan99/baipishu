

楼与股票交易制度设计

核心遵循：所有权为劳动结晶的存量确权，交易仅围绕“存量本身”展开，彻底剥离炒作空间，让楼回归居住属性、股票回归企业发展属性，杜绝任何不劳而获的食利行为，契合“存量神圣不可侵夺，增量公平分享”的天道总纲。

一、楼房交易制度（无炒楼空间，回归居住本质）
核心原则
楼房交易价格仅锚定“建筑成本-年度折旧”，开发商、房东仅能收回自身合法劳动形成的存量，无任何溢价空间，从根源上杜绝炒楼行为，让楼房成为“居住载体”而非“投机工具”。

具体规则
1. 开发商销售规则：楼房销售价格 = 全部建筑成本（含开发商的决策劳动、管理劳动报酬，工人的施工劳动报酬，销售的执行劳动报酬），无任何利润加成、无任何溢价。例如：总建筑成本70万元的楼房，开发商统一售价70万元，所有参与楼房建设、运营的劳动者（开发商、工人、销售）的劳动报酬，均已纳入这70万元成本，开发商不得额外获利，仅获得自身劳动对应的合理回报。

2. 折旧规则：楼房统一设定70年使用年限，到期必须依法拆除（回归土地原始状态，避免存量长期固化、形成世袭特权）；年度折旧额 = 总建筑成本 ÷ 70年，按年累计折旧，折旧后存量逐年递减。例如：70万元成本的楼房，每年折旧1万元，第10年存量为60万元，第70年存量为0元。折旧规则非一成不变，房东的维护投入可视为劳动增量，折旧期可协议延长。

2.1 强制拆除优良建筑违背了物理规律和生态节约原则，可“账面折旧归零，物理状态公有”。
第70年时，该楼房的“存量账面价值”确实折旧为0，原持有者的存量确权凭证销毁。
但建筑的物理实体如果不危破，不予拆除，其物理形态自动无偿移交“共同体土地与住房公共池”。原房东若继续居住，需向共同体缴纳极低的标准维护费（不涉及存量买卖）。这样既打破了“世袭房产特权”，又避免了社会资源的巨大浪费。

3. 房东处置规则：房东购入楼房后，无论选择转售还是出租，终身仅能收回自身持有的“当前存量”（建筑成本 - 已累计折旧），无任何增值收益。某地段的房子因地段的发展而多人购买时，应加大该地段的开发，尽量满足多数人的需求。

3.1 明确确立“空间正义”原则。某地段因为建了医院、地铁而变得“好住”，这是全社会劳动创造的增量，绝不能反射给该地段的房东。因此，无论地段多好，房屋的交易基准永远只能是“砖头+人工的物理折旧”。
        
  - 转售：交易价格 = 当前存量，买方支付的金额仅对应房东未折旧的存量部分，无溢价可赚，炒楼者无利可图，自然退出市场；
  - 出租：租金总额（70年周期内）≤ 当前存量，房东仅能通过出租收回自身存量，无法通过租金实现“不劳而获”，租金回归“房屋使用价值”本身，而非投机收益。

4. 核心目的：彻底剥离楼房的“投机属性”，让楼房回归居住本质。开发商、房东均无法通过“占有房产所有权”获得超额收益，仅能收回自身劳动形成的存量，从根源上杜绝炒楼、囤房等食利行为，实现“居者有其屋”的公平，契合“所有权不创造增量，仅为存量守护权”的核心逻辑。

二、股票交易制度（无炒股空间，回归企业发展本质）
核心原则
股票仅作为“企业资本劳动的存量确权”和“企业发展筹资工具”，交易价格严格锚定企业净资产价值，无溢价、无炒作空间；股票的核心价值的是“参与企业发展、获得劳动对应的增量回报”，而非投机套利。

具体规则
1. 初始股东界定：初始股东必须是“付出资本劳动的主体”——即承担企业决策风险、投入存量资本、参与企业管理，与劳方共同创造增量的资方。初始股票价值 = 初始股东投入的存量资本 + 初始决策劳动、管理劳动对应的价值，本质是“资本劳动的存量确权”，而非“单纯的资本占有权”。

2. 交易规则：股票所有交易（二级市场转让）价格，必须严格等于企业当前净资产价值（每股净资产 = 企业所有者权益 ÷ 总股本），不允许任何溢价、折价交易，彻底堵死投机炒作的空间。例如：某企业每股净资产10元，股票交易价格只能是10元，买卖双方仅能实现“存量的转移”，无法通过交易获得不劳而获的收益。

2.1 只要有波动空间，依然会产生“微秒级套利”，做市商本质上依然是不劳而获的“食利阶层”。必须实行“净资产绝对平移制”，废除传统意义的二级市场撮合交易。
新模式：“水库蓄水池交易法”。企业本身就是一个蓄水池。股东想退出，不是把股票“卖”给另一个投机者，而是以当前每股净资产为对价，“卖回”给企业的公共资本池，企业收回确权凭证；新人想加入，直接以当前净资产向企业“申购”新增发的凭证。买卖双方永远不直接交易，彻底斩断击鼓传花链条。

3. 增资扩股规则：当多人看好企业发展、愿意成为股东（付出资本劳动），企业可按“当前每股净资产价值”，新增发行股票，吸纳新的资本劳动投入，所筹资金全部用于企业生产经营、扩大产能、创造增量，而非股东套现。

  - 正向循环：企业经营良好、被市场认可 → 多人愿意投入资本劳动 → 企业增资扩股获得资金 → 扩大生产创造更多增量 → 企业净资产提升 → 股票价值同步提升（仅反映存量增加，非炒作溢价）；
  - 反向约束：无人看好企业发展、无人愿意购买股票 → 企业无法增资扩股 → 缺乏资金支持，难以发展 → 若持续亏损，净资产下降 → 股票价值同步下降，最终被市场淘汰（契合“能者上、庸者下”的天道规则）。

4. 股东收益规则：股东的收益仅来自“企业增量创造的分红”，而非股票交易溢价——企业盈利（增量）后，按股东投入的资本劳动占比，公平分配分红，分红本质是“资本劳动的报酬”；若企业亏损，股东需按持股比例，承担对应亏损（呼应“亏了全算资方的”核心规则），无任何保本特权。

5. 核心目的：彻底剥离股票的“投机属性”，让股票回归“企业发展筹资工具”和“资本劳动报酬载体”的本质。炒股者无法通过低买高卖套利，仅能通过付出资本劳动、承担企业风险，获得企业增量创造的合理回报；企业则能通过公平的增资扩股，获得发展资金，实现“资本劳动与执行劳动共生共利”，推动社会增量持续创造。

三、制度核心闭环（契合天道总纲）
1.  杜绝食利：楼和股票的交易均无溢价空间，炒作者、囤货者无利可图，彻底退出市场，仅留下“付出劳动、创造价值”的参与者（开发商、劳动者、核心股东）；

2.  存量确权：楼的成本、股票的净资产，均对应“劳动创造的存量”，交易仅围绕存量转移，不侵犯任何劳动者的合法存量，契合“存量神圣不可侵夺”；

3.  增量导向：企业通过增资扩股获得资金、创造增量，股东通过承担风险获得增量分红，开发商、劳动者通过劳动获得合理报酬，所有收益均来自劳动与增量创造，契合“增量公平分享”；

4.  自平衡运行：无需政府强制监管，市场自身可实现筛选——优质企业获得资金发展，劣质企业被淘汰；楼房回归居住，无炒楼乱象，整个系统自动守中、自动优化，契合“天道无为而无不为”。
